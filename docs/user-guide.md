# User guide
Start the server and connect with the environment API token. Overview shows actual outcomes separately from mock counts. Generate a campaign for a product, then open Approvals. Review the destination, exact content, claims and sources. Save changes to create a new version. Approve the current payload, then Execute mock to receive a sandbox receipt. Reject removes execution authorization. Pause all stops planning, approval, scheduler work and execution until resumed.

Portfolio shows strategy hypotheses and planning targets. Channels lists all 50 manual submission destinations, each requiring fresh rules verification. Pipelines records customers, institutional opportunities, investors, partners and champions. Record paid events only when verified; enter amounts as cents. Calendar schedules internal draft preparation, not publication. Agent activity shows deterministic mock jobs. Audit trail shows action hashes and decisions.

Do not paste production secrets into drafts or lead notes. Never represent mock receipts as published content or targets as acquired customers.
